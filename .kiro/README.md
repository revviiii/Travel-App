# Kiro project materials

This directory records the Kiro materials used to direct and review Pinara's
hackathon implementation.

- `steering/product.md` describes the product goals and user workflow.
- `steering/tech.md` defines the architecture and security boundaries.
- `steering/structure.md` defines repository ownership and conventions.
- `specs/pinara-mvp/requirements.md` records testable product requirements.
- `specs/pinara-mvp/design.md` maps those requirements to the system design.
- `specs/pinara-mvp/tasks.md` records the implementation and validation plan.

The team used these materials with Kiro's repository context, terminal, and IDE
workflows. Requirements were refined from the team's idea document, low-fidelity
Figma screens, implementation feedback, emulator tests, and API/database tests.
